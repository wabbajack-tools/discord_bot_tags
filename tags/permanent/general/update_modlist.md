## Updating a Wabbajack Modlist

Before updating, read the modlist's changelog and update instructions. Some updates may require additional steps or a fresh installation.

**To update an existing installation:**
1. Back up any personal modifications you want to keep, including custom profiles, configuration changes, and manually installed mods.
2. Open Wabbajack and select the latest available version of the modlist.
3. Select the same installation and downloads directories used previously.
4. Start the installation and follow any prompts.

Wabbajack will verify existing files and update the installation as required.

**Preserving custom mods:**
You can prefix the names of custom mod directories with `[NoDelete]` to prevent Wabbajack from deleting those directories during an update.

However, `[NoDelete]` does not guarantee that other customised files, profiles, or configurations will be preserved, nor does it ensure compatibility with the updated modlist.

**Modified installations are generally unsupported unless the modlist author explicitly states otherwise.** Existing saves may also become incompatible after an update.
