## Microsoft .NET Runtime

If Wabbajack reports that a required .NET runtime is missing, install the appropriate runtime from Microsoft.

Current Wabbajack versions use **.NET 10**.

Download the **.NET 10 Desktop Runtime (x64)**:
https://dotnet.microsoft.com/en-us/download/dotnet/10.0

The Desktop Runtime includes the standard .NET Runtime, so installing both separately is unnecessary.

Restart Wabbajack after installation.

**Note:** A runtime installation is only necessary when the application or its error message indicates that one is missing. Older Wabbajack versions or third-party tools may have different requirements.
