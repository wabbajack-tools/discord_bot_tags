## Texconv Errors

A `texconv` error indicates that Wabbajack encountered a problem while processing or converting texture files. This may be caused by missing or damaged runtime dependencies, corrupted files, or other system-related issues.

**Troubleshooting:**

1. Download and install or repair the following Microsoft components:
   - **.NET 10 Desktop Runtime (x64):** https://dotnet.microsoft.com/en-us/download/dotnet/10.0
   - **Microsoft Visual C++ Redistributable (x64):** https://aka.ms/vs/17/release/vc_redist.x64.exe
2. Restart Windows after installing or repairing these components.
3. Restart Wabbajack and resume the installation using the same installation and downloads directories.

If the error persists, upload your `Wabbajack.current.log` to the appropriate support channel.

**Do not delete your downloads or existing installation unless specifically instructed to do so.**
