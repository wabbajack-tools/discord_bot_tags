## Storefront Support

Wabbajack modlist compatibility depends on the game version and distribution platform supported by the individual modlist. It only supports legitimately purchased copies of the base game and/or DLC.

### Xbox Game Pass / Microsoft Store Compatibility / Xbox Cloud hosting / Nvidia Go / Amazon Luna

Wabbajack's gamefinder does not support these hosting services. 

### GOG / EA / Epic Games
Lists have to be built against a specific storefront/ While these Storefronts are supported in the Wabbajack app, the individual lists may not. You will need to check the list readme for supported storefronts.

### Cracked / SteamEMU
Cracking/Piracy is software theft, we will not support any user running a cracked version.

## **Before attempting installation:**
1. Check the modlist's README for supported game editions and platforms.
2. Confirm that your game version matches the modlist's requirements.
3. Do not assume that compatibility with a Steam, or GOG release also means compatibility with other storefronts.

**If the list readme does not explictly say what storefronts are supported, consult the modlist's support discord before proceeding. Wabbajack staff cannot tell you what versions are supported.**
