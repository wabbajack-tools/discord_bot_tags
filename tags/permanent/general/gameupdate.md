### Game Updates and Modlist Compatibility

Game and/or Creation Kit version updates require modlists to be recompiled in order for normal installation to work. If your chosen modlist has not been recompiled for the current game version, you will need wait for the modlist to be updated or downgrade the game version.

**WABBAJACK DOES NOT PROVIDE SUPPORT FOR DOWNGRADING GAME VERSION**

Refer to the modlist support server for more information.
