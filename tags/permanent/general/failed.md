## Resuming a Failed Installation

A failed Wabbajack installation does not necessarily require starting from scratch.

1. Identify and resolve the issue that caused the installation to fail.
2. Restart Wabbajack and select the same modlist.
3. Select the **same installation and downloads directories** used previously.
4. Start the installation again.

Wabbajack will verify existing files and reuse valid downloads where possible, processing or downloading anything still required.

**File Deletion Warning:**

You may be prompted to confirm the deletion of files not belonging to the modlist. When resuming a failed installation, these are generally temporary or leftover files. During modlist updates, outdated or modified files may also be removed. Check the warning before continuing, particularly if you have manually added files.

If the installation fails again, upload your latest `Wabbajack.current.log` to the appropriate support channel.

**Do not delete your downloads or installation directory simply because an installation failed.**
